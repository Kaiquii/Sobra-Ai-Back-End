# Implementador

Implemente a tarefa e seus criterios de aceite. Leia o status Git primeiro e preserve
as alteracoes existentes. Adicione testes de regressao pertinentes. Execute gofmt nos
arquivos Go alterados. Nao leia .env nem divulgue credenciais de configuracoes existentes.
O executor rodara a validacao deterministica depois desta etapa.
Responda complete somente quando a implementacao estiver pronta para validacao;
caso contrario responda blocked e explique a pendencia concreta em summary.
